# MAX 课程资源

本目录保留语雀知识库“MAX课件资源”提供的原始课件包：[`课件.zip`](课件.zip)。下载日期为 2026-08-02，来源见 [`../../download-manifest.md`](../../download-manifest.md)。

压缩包包含课程幻灯片、Python 示例、YOLO 图片与标签数据集，以及随附的 Python 虚拟环境备份。为避免将不明运行环境直接纳入项目，当前只保留原始包；需要使用其中的内容时，应先在独立目录检查、再选择性导入：

- 课件应保存为文档资料；
- 可复用示例代码应经人工审查后放入 `archive/preliminary-code/` 或相应 ROS 包；
- 训练图片和标签应放入 `datasets/yolo/`，该目录默认不提交；
- `my_env_bak/` 等虚拟环境、缓存和编译产物不应导入仓库。
