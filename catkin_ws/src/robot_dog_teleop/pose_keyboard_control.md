# 车体姿态键盘控制指令文档

本文档说明 `robot_dog_teleop` 包中 `pose_keyboard_teleop.py` 的全部控制指令、关节映射、
控制范围、终端显示与姿态记录格式。它面向实机操作人员，使用前请先阅读「安全前提」与
「首次使用清单」。

## 一、概述

该程序用键盘逐关节调整机器狗车体姿态，覆盖机械爪、前腿和后腿共 15 个关节
（`j1`–`j15`）。每个关节对应一个舵机，按键只发出有界步长的绝对角度目标，舵机保持最近
一次目标角；不存在持续运动，也不需要看门狗。终端底部固定显示当前姿态，可随时抄录或
按 `r` 一键写入文件。

程序沿用运动键盘的 `u`、`y` 双确认安全模式：默认锁定，不会因启动而运动；只有显式武装
后按键才会向舵机发送真实命令。它不打开串口，只调用机器上已有的 OUMAX 手控服务
（`127.0.0.1:8765`），该服务是 `/dev/ttyAMA0` 的唯一持有者。

## 二、安全前提

- 仅在原厂 UI 已由 `raicom-control-handover` 接管、OUMAX 手控服务健康时运行。
- 首次实机测试须：机器已充电、站稳、四周至少留出 1 m 净空、无人位于运动方向、实体急停
  或断电可达。
- 首次只按 `m` 验证一次回中行为，随后用 `w`/`s` 以最小细步（默认 1°）验证单个关节
  方向，确认无异常后再扩大步长。
- 禁止同时启动其他手柄、APP、raw-XGO 或串口控制程序。
- 单关节步进会改变腿的姿态稳定性，调到极限角度可能使机器失稳；接近范围端点时须格外
  谨慎。

## 三、启动方式

部署后，在宿主机执行：

```bash
sudo /usr/local/sbin/raicom-launch-pose-keyboard
```

该启动器会先接管串口（停止原厂 UI、启动 OUMAX 手控服务并检查健康），再进入 ROS 容器
运行 `roslaunch robot_dog_teleop pose_keyboard_teleop.launch enable_motion:=true`。退出
时自动恢复原厂 UI。

launch 参数可在启动时覆盖：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `enable_motion` | 无默认（必填） | 必须显式设为 `true` 才允许真实运动 |
| `fine_step` | `1.0` | `w`/`s` 细步步长（度） |
| `coarse_step` | `10.0` | `q`/`e` 粗步步长（度） |
| `record_file` | `/tmp/xgo_poses.log` | `r` 记录姿态的文件路径 |

- **前腿**：`j1`–`j6`（左前 `j1`/`j2`/`j3`，右前 `j4`/`j5`/`j6`）

- **机械爪**：`j13`
- **机械臂**：`j14`（小臂）、`j15`（大臂）

每条腿三个舵机自下而上依次为：小腿（下）、大腿（中）、髋（上）。

## 五、按键指令

程序运行时终端处于 raw 模式，按键即时响应。下表列出全部按键符号及其作用。「武装前」指
未通过 `u`、`y` 解锁时；「武装后」指已解锁、可发送真实舵机命令时。

| 按键符号 | 作用 | 武装前行为 | 武装后行为 |
| --- | --- | --- | --- |
| `u` | 请求武装 | 进入 5 秒武装请求窗口，提示按 `y` 确认 | 重新请求武装（已武装时无意义） |
| `y` | 确认武装 | 在 5 秒窗口内按下则武装成功，开始接受运动按键 | 无动作 |
| `[` | 选择上一个关节 | 仅切换当前关节（更新显示） | 同左，且后续步进作用于新选中关节 |
| `]` | 选择下一个关节 | 仅切换当前关节（更新显示） | 同左 |
| `w` | 当前关节细步 `+fine_step` | 仅更新本地跟踪值，不发送命令 | 发送 `kind=motor` 命令并更新本地值 |
| `s` | 当前关节细步 `-fine_step` | 仅更新本地跟踪值 | 发送命令并更新本地值 |
| `q` | 当前关节粗步 `+coarse_step` | 仅更新本地跟踪值 | 发送命令并更新本地值 |
| `e` | 当前关节粗步 `-coarse_step` | 仅更新本地跟踪值 | 发送命令并更新本地值 |
| `m` | 全部关节回中 | 仅更新本地跟踪值为默认值 | 逐关节发送回中命令并更新本地值 |
| `r` | 记录当前姿态到文件 | 把当前本地姿态追加写入记录文件 | 同左 |
| `空格` | 立即锁定 | 保持锁定状态 | 立即锁定，停止接受运动按键，舵机保持当前角度 |
| `x` | 立即锁定 | 同空格 | 同空格 |
| `h` | 显示帮助 | 打印按键说明 | 同左 |
| `Ctrl-C` | 第一次锁定，第二次退出 | 第一次锁定；第二次退出程序 | 第一次锁定停止；第二次退出程序 |

符号说明：

- `[` / `]`：方括号键，用于在 15 个关节之间循环切换「当前选中关节」。`[` 向编号减小
  方向（到 `j1` 后绕回 `j15`），`]` 向编号增大方向（到 `j15` 后绕回 `j1`）。
- `w` / `s` / `q` / `e`：字母键，控制当前选中关节的角度增减。`w`/`q` 增大角度，
  `s`/`e` 减小角度；`w`/`s` 为细步（默认 1°），`q`/`e` 为粗步（默认 10°）。
- `m`：回中键，把全部 15 个关节恢复到上表「默认值」。
- `r`：记录键，把当前姿态以可抄录格式追加写入记录文件。
- `u` / `y`：武装双确认，先按 `u` 请求、5 秒内按 `y` 确认，之后运动按键才会发送真实
  命令。
- `空格` / `x`：锁定键，立即停止发送命令并锁定，舵机保持当前角度。
- `Ctrl-C`：raw 模式下作为字节 `\x03` 处理，第一次锁定停止，第二次退出程序。

步进会自动按当前关节的控制范围钳制：若目标角超出范围则取端点值；若当前已在端点且步进
方向朝外，则该次按键视为无操作（不发送命令、不更新显示）。

## 六、操作流程

1. **启动**：执行 `sudo /usr/local/sbin/raicom-launch-pose-keyboard`，等待出现
   `POSE keyboard teleop is LOCKED` 提示与底部姿态显示。
2. **武装**：按 `u`，屏幕提示 `ARM REQUESTED`；在 5 秒内按 `y`，提示
   `ARMED (REAL OUMAX MOTORS)` 后运动按键才生效。
3. **选关节**：按 `[` 或 `]` 切换当前关节，状态行显示当前关节名与角度。
4. **调角度**：按 `w`/`s` 细步或 `q`/`e` 粗步调整当前关节角度，姿态行实时更新。
5. **记录**：调到目标姿态后按 `r`，当前姿态追加写入记录文件，屏幕提示 `RECORDED: ...`。
6. **锁定**：按 `空格` 或 `x` 立即锁定，舵机保持当前角度，不再接受运动按键；需再次
   调整时按 `u`、`y` 重新武装。
7. **退出**：按 `Ctrl-C` 两次退出程序；退出时自动恢复终端并锁定，启动器随后恢复原厂 UI。

## 七、终端显示说明

终端底部固定三行实时重绘（ANSI 清行，不滚动）：

- **第 1 行（状态行）**：`关节 jX 角度 A 细步 F 粗步 C 状态`
  - `jX`：当前选中关节编号（如 `j7`）。
  - `A`：当前选中关节的角度值。
  - `F`：细步步长（`fine_step`）。
  - `C`：粗步步长（`coarse_step`）。
  - `状态`：`已武装` 或 `已锁定`。
- **第 2 行（姿态行 1）**：`j1 v, j2 v, j3 v, j4 v, j5 v, j6 v, j7 v, j8 v`
- **第 3 行（姿态行 2）**：`j9 v, j10 v, j11 v, j12 v, j13 v, j14 v, j15 v`

姿态行按 `j1`–`j15` 顺序列出全部 15 个关节的当前角度，关节名与值之间用空格分隔，关节之
间用 `, ` 分隔。两行均不超过 80 字符，在 80 列终端不会换行，便于直接抄录。

提示信息（如 `ARMED`、`RECORDED`、帮助文本）会打印在姿态行上方，打印后自动重绘底部三
行，布局保持稳定。

## 八、姿态记录格式

按 `r` 时，程序向记录文件（默认 `/tmp/xgo_poses.log`，可用 `record_file` 覆盖）追加一行
UTF-8 文本，格式为：

```text
[YYYY-MM-DD HH:MM:SS] j1 v, j2 v, j3 v, j4 v, j5 v, j6 v, j7 v, j8 v, j9 v, j10 v, j11 v, j12 v, j13 v, j14 v, j15 v
```

示例：

```text
[2026-08-09 14:30:21] j1 0, j2 0, j3 0, j4 0, j5 0, j6 0, j7 0, j8 0, j9 0, j10 0, j11 0, j12 0, j13 0, j14 70, j15 -85
```

每行含时间戳与完整 15 关节姿态，可直接复制到笔记或脚本中复现姿态。写盘失败时屏幕打印
`RECORD FAILED: ...` 但程序继续运行。

## 九、异常与锁定

下列情况会立即锁定（停止发送命令、`状态` 变为 `已锁定`），需重新 `u`、`y` 武装：

- 按空格、`x` 或第一次 `Ctrl-C`。
- 舵机命令被 OUMAX 服务拒绝（网络异常、服务返回错误、超时），屏幕打印
  `MOTOR COMMAND REJECTED: ...`。
- ROS 关闭或节点退出。

锁定后舵机保持最近一次目标角度，不再接收新目标；本地跟踪的姿态值保留，重新武装后可继
续从当前值步进。

## 十、首次使用清单

- [ ] 机器已充电、站稳，四周净空 ≥ 1 m，急停/断电可达。
- [ ] 已运行 `install_host_handover.sh --cutover`，启动器已安装。
- [ ] 启动后出现 `POSE keyboard teleop is LOCKED` 与底部姿态显示。
- [ ] 按 `u`、再按 `y` 武装，确认提示 `ARMED`。
- [ ] 先按 `m` 回中，目视确认机器回到默认姿态、无异常抖动。
- [ ] 用 `[`/`]` 选中一个非承重关节（如 `j13` 夹爪），按 `w` 以最小细步验证方向。
- [ ] 确认方向与停止行为无误后，再逐关节、逐小步调整目标姿态。
- [ ] 调到目标姿态后按 `r` 记录，从记录文件或终端姿态行抄录数值。
- [ ] 完成后按 `空格` 锁定，再按 `Ctrl-C` 两次退出，确认原厂 UI 恢复。
