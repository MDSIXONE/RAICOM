# AI 工作记录

此目录保存可跨对话复用的开发经验。不要删除历史记录，也不要虚构未发生的事件。

| 文档 | 读取时机 | 写入时机 |
| --- | --- | --- |
| `CHANGE_LOG.md` | 每次开启新对话时 | 每次完成代码改动后；开始实现时可先建“进行中”单元 |
| `MISTAKE_LOG.md` | 每次开启新对话前 | 出现可复用的错误教训并确认原因后 |
| `FAILED_APPROACHES.md` | AI 准备采用新方案前 | 用户明确原方案失败，或必须切换方案时 |

详细执行流程见 Codex 技能 `project-memory-records` 与仓库根目录的 `AGENTS.md`。
