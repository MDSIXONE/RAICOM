# 2026-08-16

### Codex 工作区命令 CreateProcessAsUserW 错误 5

- **现象**：Codex 在工作区启动 PowerShell 命令时返回 `CreateProcessAsUserW failed: 5 (拒绝访问)`，无法读取文件或执行 Git。
- **原因**：当时任务的终端执行环境未获得工作区进程创建权限；仓库和 Git 远端连接本身没有异常。
- **修复**：恢复允许创建工作区进程的执行环境后，重新读取项目记录、获取远端并以快进方式更新本地分支。
- **预防**：遇到错误 5 时先确认 Codex 任务的终端/权限环境，再重试命令；不要将该错误误判为 Git、远端凭据或仓库文件权限故障。
