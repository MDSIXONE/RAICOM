# 机器狗全量源码快照

采集日期：2026-08-02。

本目录是当前机器狗的**非系统用户/厂商/服务源码**快照，不是远程 Debian 根文件系统镜像，也不是可直接运行的 Docker 或 ROS 工作区。

## 目录映射

| 本地目录 | 远程来源 | 内容 |
| --- | --- | --- |
| `home-pi/` | `/home/pi/` | CM5 公共代码、所有机器人型号演示代码、UI 工具和本地控制服务源码 |
| `systemd/` | `/etc/systemd/system/` | 引用用户源码的自定义 systemd 服务定义 |
| `SHA256SUMS.tsv` | 采集时生成 | 每个导入文件的相对路径、字节数和 SHA-256 摘要 |

## 导入规则

当前快照包含 590 个文件、共 6,529,017 字节。目录按文本源码、构建说明和无凭据配置筛选；包含当前与非当前机器人型号的应用源码，以便进行整体接口研究。

以下内容不会导入：操作系统文件、Python 虚拟环境、第三方依赖目录、模型和权重、媒体、日志、PID、缓存、构建产物、Git 元数据、运行状态和数据库。

初次筛选与预推送复核共剔除了 27 份含密码、令牌或 API 密钥字面量的源码/配置；同时剔除了 Python 打包元数据和人脸检测模型文件。它们不能提交到仓库。如需恢复相应功能，应使用 Git 忽略的本地配置或环境变量重新提供凭据。

## 验证结果

- 所有清单文件的大小与 SHA-256 摘要已校验一致。
- 未发现构建产物、虚拟环境、密钥文件或长凭据字面量。
- 导入的 Python 文件已完成语法解析；当前 Windows 环境未尝试执行依赖 ARM 硬件的程序。

## 使用方式

此目录只用于理解厂商代码与提取接口。新实现应进入 `robot-src/catkin_ws/src/` 的独立 ROS 包；不要把整个快照直接放入 Catkin 工作区或部署回机器狗。
